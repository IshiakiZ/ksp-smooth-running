# Smooth Running

The game made faster where it wastes its time, for Kerbal Space Program 1. Each fix changes the game's own code as it
runs (through Harmony; nothing on disk is touched), is made only after the time it wastes was measured in the game, and
can be switched off on the mod's page. The short version is on the repository's front page.

* [How it works](How-it-works.md): each fix, what it costs the game without it, and how that was measured
