Smooth Running @VERSION@
for Kerbal Space Program 1.12.x

The game made faster where it wastes its time, each fix measured in the game first.
What it mends:
  * the terrain's update: the game starts it again at every load and scene change and
    never stops the last one. Smooth Running ends the extra copies.
  * handlers of things that are gone, cleared at every scene change.
  * one clean-up too many at every scene change, left out.
  * (0.3.0) each frame at its own moment: every craft drawn where it has got to when the
    frame is drawn, so the world no longer goes in jumps.
  * (0.3.0) frame blending: each frame blended along the way things moved, as a film
    camera's shutter blends it; the craft the camera follows stays sharp.
  * (0.3.0) the first lift-off's code compiled a little at a time beforehand.
  * (0.3.0) the terrain held to 8 ms a frame under time warp.
  * (0.3.0) a launch's terrain built once, not twice: about a second off every launch.

INSTALL
  This mod needs Keystone 0.9 or later, the base it stands on, and Harmony (HarmonyKSP), which are
  separate downloads:
    https://spacedock.info/mod/4665/Keystone
    https://github.com/KSPModdingLibs/HarmonyKSP
  Copy Keystone's folder (Keystone) and Harmony's (000_Harmony) into your KSP's GameData
  folder, and the SmoothRunning folder from this download beside them, and start the
  game. Without them the game does not load this mod. To remove it, delete the
  SmoothRunning folder.

USE
  It is on as installed. Its switches, and what each fix has done, are in the Keystone
  window: the keystone button on the game's toolbar, or Option-K on
  a Mac and Alt-K elsewhere. It changes some of the game's code as the game runs; nothing
  on disk is touched. Switch a fix off and that part is the game's own again.

WHERE IT WORKS
  Made and tried on a Mac, and tried on Windows 11 (Direct3D 11 and OpenGL) on
  2026-10-20: the frame blending's shader built for Direct3D and loaded on both, a launch
  filmed on each with no doubled rocket. Nobody has run it on Linux yet.

Everything else: https://github.com/IshiakiZ/ksp-smooth-running
